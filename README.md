# 🏆 Sports Team Selection System

A Java console-based application that helps coaches manage player records, maintain skill ratings, select players for practice sessions, and generate practice group reports.

## 📌 Project Overview

The **Sports Team Selection System** is developed using Java and JDK 21. It provides a simple way to register players, track their performance ratings, and organize a practice group of up to five players.

The application also saves player information and group selections in text files, allowing data to be loaded again when the application restarts.

## ✨ Features

- **Player Registration:** Register players as Attacker or Defender.
- **View Players:** Display player details, skill ratings, and total scores.
- **Update Ratings:** Modify player skill ratings.
- **Duplicate Prevention:** Prevent duplicate jersey numbers.
- **Practice Group Management:** Assign players to five available slots, with one player per slot.
- **Clear Slots:** Remove players from selected practice slots.
- **Group Reports:** Display selected players, total ratings, and average ratings.
- **File Handling:** Save and load player records and group selections.
- **Input Validation:** Handle invalid inputs and prevent duplicate group selections.

## 🛠️ Technologies Used

- Java
- JDK 21
- Object-Oriented Programming (OOP)
- Java Collections Framework
- File Handling
- Exception Handling

## 🧠 Java Concepts Demonstrated

- **Encapsulation:** Keep player data private and access it through methods.
- **Inheritance:** `Attacker` and `Defender` extend the abstract `Player` class.
- **Abstraction:** Define common player behavior through an abstract class.
- **Polymorphism:** Implement role-specific behavior using method overriding.
- **Arrays:** Store skill ratings and practice group slots.
- **ArrayList:** Maintain player records.
- **HashSet:** Track jersey numbers and prevent duplicates.
- **Exception Handling:** Handle invalid inputs and file errors.
- **File Handling:** Persist player and group information between runs.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Naveen-092/sports-team-selection-system.git
```

### 2. Navigate to the Project

```bash
cd SportsTeamSelectionSystem
```

### 3. Compile the Java Files

If all seven Java files are in the same source directory and use the default package:

```bash
javac -d out src/*.java
```

### 4. Run the Application

```bash
java -cp out Main
```

If you use a Java IDE, import the project, ensure the files are in the same package, and run `Main.java`.

## ⭐ Player Rating System

Each player has three skill ratings:

| Skill | Rating Range |
|---|---:|
| Fitness | 0–10 |
| Speed | 0–10 |
| Teamwork | 0–10 |

**Total Rating = Fitness + Speed + Teamwork**

The maximum total rating for a player is 30.

## 💾 Data Storage

The application uses text files to store information:

- `players.txt` — player IDs, roles, names, jersey numbers, and ratings.
- `team.txt` — player IDs assigned to the five practice slots.
- `report.txt` — a readable practice group report generated by the application.
